__lasx_xvmulwev_h_bu_b

LASX intrinsic · group: Integer Computation

Synopsis

__m256i __lasx_xvmulwev_h_bu_b (__m256i a, __m256i b)
#include <lasxintrin.h>
Instruction: xvmulwev.h.bu.b xr, xr, xr
CPU Flags: LASX

Description

Multiply the even-positioned unsigned 8-bit elements in a and the corresponding signed 8-bit elements in b, extending both to 16-bit, and save the 16-bit result in dst.

Operation

for (int i = 0; i < 16; i++) {
  dst.half[i] = (u16)(u8)a.byte[2 * i] * (s16)(s8)b.byte[2 * i];
}

// Expands to:

if (0) {
