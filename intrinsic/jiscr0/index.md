# jiscr0

LBT intrinsic · group: [LBT Jump](https://jia.je/unofficial-loongarch-intrinsics-guide/lbt/jump/index.md)

### Synopsis

```
Instruction: jiscr0 imm
CPU Flags: LBT
```

### Description

Jump via scratch register 0: add `imm` to the value in SCR[0] and jump to the resulting address.
