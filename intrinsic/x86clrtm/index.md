# x86clrtm

LBT intrinsic · group: [x86 FPU](https://jia.je/unofficial-loongarch-intrinsics-guide/lbt/x86_fpu/index.md)

### Synopsis

```
Instruction: x86clrtm
CPU Flags: LBT
```

### Description

Clear x87 FPU stack translation mode: disable TOP-based remapping of FPR registers.
