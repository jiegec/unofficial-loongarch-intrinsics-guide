# str.w

LBT intrinsic · group: [MIPS Memory](https://jia.je/unofficial-loongarch-intrinsics-guide/lbt/mips_memory/index.md)

### Synopsis

```
Instruction: str.w rd, rj, imm
CPU Flags: LBT
```

### Description

MIPS-style store doubleword right: store right part of value in `rd` to unaligned memory address `rj + imm`.
