## Samp family: parameter map

This table maps each variant to the GLSL 330 trigger that reaches it, to the
parameter the texture unit supplies implicitly, and to the value observed on
LG200.  Reference texture: 16x16 RGBA8, 4 mip levels, level L base color
mip[L] = {(16,80,144),(192,96,48),(128,64,32),(64,32,16)} and an x-gradient
r = mip.r + tx*96/(size-1); depth texture for shadow: depth(x) = (x+0.5)/16,
GL_COMPARE_REF_TO_TEXTURE.

### Variant to GLSL 330 trigger to implicit parameter to observed result

| Variant | GLSL 330 trigger form | Implicit parameters | Observed |
| ------- | --------------------- | ------------------- | ------------- |
| samp | `texture(tex, coords)` | LOD from coord derivatives (lambda=log2 rho) | lambda 0 -> level 0 texel 7 (r=60) |
| samp_b | `texture(tex, coords, bias)` | lambda = log2 rho + bias | bias 1.0 -> level 1 (r=233), bias 2.0 -> level 2 (r=160) |
| samp_b_cl | `texture(tex, coords, bias)` + MIN/MAX_LOD | lambda = clamp(log2 rho + bias, min, max) | bias 2.0 clamp [1,1] -> level 1 |
| samp_b_cl_o | `textureOffset(tex, coords, ivec2, bias)` + MIN/MAX_LOD | clamp + offset added to coord | clamp [1,1] offset (1,0) -> level 1 texel x+1 |
| samp_b_o | `textureOffset(tex, coords, ivec2, bias)` | bias + offset | bias 1.0 offset (1,0) -> level 1 texel x+1 |
| samp_c | `texture(sampler2DShadow, vec3(coord, ref))` | compare depth vs ref with compare func | LEQUAL 0.30<=0.46875 -> 1.0; 0.50 -> 0.0; GEQUAL 0.55 -> 1.0 |

### Implied ABI summary

- Coordinate tuple: `(u, v)` for 2D, `(u, v, layer)` for 2D-array, `(u, v, z)` for
  3D, `(u, v, ref)` for shadow, direction vector for cube. Array layer is an
  integer (0..N-1); 3D z is normalized (floor(z_norm * depth)).
- LOD selection: implicit (from derivatives, lambda = log2 rho), bias added,
  clamp [min_lod, max_lod], explicit LOD, explicit zero LOD, or explicit
  gradients (dPdx/dPdy). Verified: bias/clamp/grad/LOD select the exact mip
  level of a 4-level image.
- Offset: NOT an instruction operand and not a fixed displacement.  The `_o` opcode variants select a
  tuple layout whose **leading slot** carries the offset, read from the `VJ` register base; it is a
  signed six-bit X/Y(/Z) texel displacement packed as `x[5:0] | (y[13:8] << 8) | (z[21:16] << 16)`
  and every other slot shifts up by one (`samp` reads `{x, y}`, `samp_o` reads `{offset, x, y}`;
  `samp_b` reads `{bias, x, y}`, `samp_b_o` reads `{offset, bias, x, y}`).  The shift is
  `coord' = coord + offset/size` applied before the sampler wrap decision.  The value comes from the tuple, so it can be a constant or a runtime value - but its granularity is
  the **4-lane fragment quad**: measured on LG200 with one shader binary over three uniform-buffer
  data patterns, an offset that is constant per 2x2 pixel block matched all 256 output pixels and a
  runtime-uniform offset matched all 256, while a per-pixel ramp mismatched 188 of 256 - the unit
  consumes one offset per quad and ignores variation inside it.  The granularity of the `bias` and
  depth `reference` tuple slots is UNRESOLVED (not measured).  The closed producer emits
  `v_mov_imm_b32 v0, 0x3e01` (= `ivec2(1, -2)`) then `samp_b_o p0, v[0:3], v[0:3], ...` for
  `textureOffset(s, vec2(0.25, 0.75), ivec2(1, -2), 2.0)`.  Negative, `y` and multi-texel
  displacements are performed across the advertised `minTexelOffset`/`maxTexelOffset` range
  (LG200: +/-8; CTS `textureoffset`).  `load_v_tex*` has no `_o` variant, so a texel-fetch offset
  must instead be folded into the integer coordinate.
- Compare: depth texture + reference value, compare function from sampler
  (LEQUAL/GEQUAL etc. all work); result is a scalar float broadcast to the
  vector destination channels.
- Descriptor: image descriptor 32 bytes (base, dimensions, format/type/layout)
  + sampler descriptor 16 bytes at +0x30 within the 0x40-byte combined
  footprint; see `docs/gpu/shader/descriptors.md`.


## Gather family: parameter map

GLSL 330 with `GL_ARB_texture_gather` reaches only
`textureGather(tex, coords)` (sampler2D/2DArray/Cube) and
`textureGatherOffset(tex, coords, ivec2)` (sampler2D/2DArray; no cube
offset).  The remaining 22 variants (b/cl/l/lz/c/component-select) have no
GLSL 330 entry point; their geometry follows the `samp` parameter map above

Offset mechanism (observed on the closed producer): GLSL `textureGather` compiles to `gather_lz`
with a `{x, y}` tuple, and `textureGatherOffset` to `gather_lz_o` with the offset prepended as the
leading tuple slot (`{offset, x, y}`, or `{offset, s, t, layer}` for a 2D array); the offset packs
exactly as `samp*_o` (`ivec2(1, -2)` becomes `0x3e01` in `v0`).  The offset opcode block
(`0x2c`-`0x37`) is separate from the no-offset block (`0x20`-`0x2b`).  Both forms clear bit 27 of the
sampler descriptor (`s_and_imm_b32 s4, s4, 0xf7ffffff`) before the gather.  The closed producer GLSL
offers `textureGather*` only for `sampler2D`/`isampler2D`/`usampler2D`/`sampler2DArray` (no shadow
entry point), so the shadow gather forms have no direct GLSL 330 oracle.and is marked accordingly.

Texture: 16x16 RGBA8, texel (x,y) r = (x*16 + y) & 0xff (unique), NEAREST,
single level.  Shader emits the four gathered r values into one RGBA output
pixel; one readback identifies the exact 2x2 block and channel order.

### Implied ABI summary

- Gather block: for sample P in texel units, (i0,j0) = floor(P); the four
  gathered texels are (i0,j0), (i0+1,j0), (i0+1,j0-1), (i0,j0-1), written
  to channels r,g,b,a respectively.
- **LOONGGPU_DELTA**: the y (v) expansion is toward DECREASING v / data
  row (j0-1), opposite to the standard GL +y expansion (j0+1).  Verified
  at two sample points and via the (0,1) offset case.
- **LOONGGPU_DELTA**: out-of-bounds on the negative edge returns an
  all-zero block (no clamp-to-edge), verified at P=(0.5,0.5)/16.
- Offset: `textureGatherOffset` shifts the entire 2x2 block by the
  constant integer offset; verified for (1,0), (-1,0), (0,1) on 2D and
  (1,0) on 2DArray layer 0 and 2.
- Cube: the direction selects the face; the block/order matches the 2D
  behavior (verified at +X and +Z face centers).
- Not reachable from GLSL 330: component select (textureGather(,comp)),
  LOD/bias forms (textureGatherLod, textureGather(,bias)), shadow gather
  (sampler2DShadow overload).  Hardware gather_b/cl/l/lz/c* variants need
  an entry point outside GLSL 330 (Vulkan, CL, or a direct shader binary) to be verified.
